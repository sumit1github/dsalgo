# intro

it is a DS follows `LIFO` => Last in First out.

it can be build using LL or Array 

```
+-----------+
|    30     |  <-- Top
+-----------+
|    20     |
+-----------+
|    10     |
+-----------+
```

# operations

1. ***Push***
    - inserting data from top
2. ***pop*** 
    - remove data from top one by one
3. ***peek***
    - to see the top/last item
4. ***empty***
    - it will tell ss the stack is empty or not
5. ***Size***
    - how many numbers/items are present

# Creation

Stack can be created using the using LL and array.

***LL*** : if you enter 1,2,3,4,5 in head one by one then the final LL will be 5 -> 4 -> 3 -> 2 -> 1 -> None. So the opearions we need to perform using head only.
